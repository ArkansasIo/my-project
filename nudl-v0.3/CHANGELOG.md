# Changelog

## 0.3 — Expression foundation and language design expansion
- Added the C++23 arithmetic expression evaluator and tests.
- Added examples covering arithmetic, datasets, tables, styles, libraries, validation, algorithms, and system configuration.
- Added a broad language specification draft covering declarations, modules, types, classes, traits, arrays, operators, errors, and runtime design.
- Added a proposed 0.4 EBNF grammar and language/type/module/AST/array/annotation documentation.
- Added proposed standard-library modules for core, math, strings, collections, data, algorithms, statistics, time, I/O, networking, and system capabilities.
- Added GitHub Actions build/test workflow.
- Most language features and standard-library modules listed in the design files are not implemented by the 0.3 compiler.
