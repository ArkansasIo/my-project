# Changelog

## NUDL 0.3.0 — 2026-10-11

- Added an independently buildable arithmetic expression evaluator.
- Added recursive-descent parsing with precedence and unary operators.
- Added diagnostics for malformed expressions, unexpected tokens, and division by zero.
- Added automated expression tests and a CMake/CTest build.
- Clarified that the expression module is experimental and not yet the complete NUDL language runtime.

## NUDL 0.2.0

- Initial lexer, dataset AST, schema validation, command-line validation, and CMake test foundation.
